計畫書文獻連結使用說明
========================

計畫書每次產出兩個版本，檔名時間戳相同，都放在 Plan_fen 資料夾：
  ・月日-時分_兩年期研究計畫書.html  ← 網頁版（建議審閱時使用，跨平台、免授權）
  ・月日-時分_兩年期研究計畫書.docx  ← Word 版（編修、列印用）
兩者內容相同。內文的文獻引用都是超連結，點擊後開啟主題資料夾中的 PDF；
尚未取得 PDF 的文獻（虛線底線）則開啟 DOI 網頁。連結一律使用「相對路徑」，以計畫書所在位置為起點。

一、資料夾結構（請保持不變）

    paper/
      ├─ Plan_fen/
      │    ├─ 月日-時分_兩年期研究計畫書.html
      │    ├─ 月日-時分_兩年期研究計畫書.docx
      │    ├─ _計畫書文獻連結使用說明.txt（本檔）
      │    ├─ 1. 主題一 創新發展 (Innovative Development)/
      │    ├─ 2. 主題二 消費者心理行為 (Consumer Psychological Behavior)/
      │    ├─ 3. 主題三 電子商務模式 (E-commerce Models)/
      │    ├─ 4. 主題四 研究潛力 (Research Potential)/
      │    └─ 5. 主題五 電商市場發展需求 (E-commerce Market Development Needs)/
      └─ Others/   ← 其他論文（計畫書的連結不依賴此資料夾）

  分享給審閱者時，只要複製整個 Plan_fen 資料夾即可（所有引用文獻都在其中），
  放在對方電腦的任何位置皆可；資料夾與檔案名稱不要更改。

二、網頁版（Windows、macOS、Linux 通用，建議）
  1. 用 Chrome、Edge、Safari 或 Firefox 開啟 .html 檔。
  2. 點擊文獻引用，PDF 會在新分頁開啟。不需要任何授權或設定。
  參考文獻清單每一筆後面另有「PDF」連結，可直接核對原文。

三、Word 版
  ・Mac：按住 ⌘ 再點擊引用。
      Mac 版 Word 受沙盒限制，每個 PDF 第一次被開啟時都會要求「授與檔案存取權」，
      且只能逐一授權單一檔案（無法一次授權整個資料夾）；已授權過的檔案之後不會再問。
      Word 另可能顯示「Microsoft Office 潛在安全性考量」，按「開啟」即可。
      這兩個提示都由 Office 控制，文件本身無法關閉；若要一次免授權開啟所有文獻，請改用網頁版。
  ・Windows：按住 Ctrl 再點擊引用；首次開啟本機檔案時 Office 可能顯示安全性提示，選「是」。
  ・計畫書未放在 Plan_fen 內時：在 Word「檔案 > 內容 > 摘要」的「超連結基底」
    填入 Plan_fen 資料夾的完整路徑。

四、尚未取得 PDF 的文獻
  取得 PDF 並放入 External References 後會歸檔到主題資料夾，計畫書重新產出時自動改連到 PDF。
