計畫書文獻連結使用說明
========================

計畫書產出兩個版本，檔名時間戳相同，放在 Plan_fen/plan-2 資料夾：
  ・月日-時分_兩年期研究計畫書.html  ← 網頁版（建議審閱時使用，跨平台、隨開即用）
  ・月日-時分_兩年期研究計畫書.docx  ← Word 版（編修、列印用）

兩者內容相同。內文的文獻引用與參考文獻清單皆為超連結：
  ・已取得 PDF 的文獻：點擊後直接於瀏覽器以線上 PDF 檢視器開啟 GitHub 公開全文（含下載按鈕）
  ・尚未取得 PDF 的文獻（虛線底線）：點擊後連至官方 DOI 出版頁面

超連結全面採用「雲端線上直連」，其他使用端無需下載龐大的主題資料夾，單獨傳送 .docx 或 .html 檔案，任何裝置皆可正常點開全文。

一、跨端分享方式（極簡）

  分享給審閱者或合作學者時：
  ・只要直接寄送「月日-時分_兩年期研究計畫書.docx」或「.html」單一檔案即可。
  ・對方無需安裝額外軟體、無需下載數百 MB 的文獻資料夾，點擊任一文獻引用即可在瀏覽器開啟線上全文。

二、雲端全文庫與備用連結

  所有引用論文的 PDF 已完整託管於雲端平台，若審閱者需要整包瀏覽或下載：
  1. GitHub 公開文獻庫：https://github.com/hauchiehlin-ops/fen_paper
  2. Google Drive 雲端文獻夾：https://drive.google.com/drive/folders/1ohW4IT7qQGQINABH0RA3BGCosj_8qgyk?usp=drive_link

三、點擊使用方式

  ・網頁版（.html）：
    直接用 Chrome、Edge、Safari、Firefox 開啟，點擊引用即在新分頁開啟全文。
  ・Word 版（.docx）：
    - Mac：按住 ⌘ (Command) 鍵再點擊引用。
    - Windows：按住 Ctrl 鍵再點擊引用。
    點擊後會由系統預設瀏覽器直接跳轉至線上全文，不再受本機沙盒或路徑錯誤干擾。

四、本機目錄結構（供計畫主持人維護使用）

    paper/
      ├─ Plan_fen/
      │    ├─ _計畫書文獻連結使用說明.txt（本檔）
      │    ├─ plan-1/   ← 封存的原計畫
      │    ├─ plan-2/   ← AI 虛擬主播與真人主播版計畫書、待下載文獻清單
      │    ├─ 1. 主題一 創新發展 (Innovative Development)/
      │    ├─ 2. 主題二 消費者心理行為 (Consumer Psychological Behavior)/
      │    ├─ 3. 主題三 電子商務模式 (E-commerce Models)/
      │    ├─ 4. 主題四 研究潛力 (Research Potential)/
      │    └─ 5. 主題五 電商市場發展需求 (E-commerce Market Development Needs)/
      └─ Others/   ← 其他論文

五、更新與同步
  若後續有新增 PDF，放入主題資料夾後：
  1. 執行 _sync_github.sh 將新檔案推送至 GitHub。
  2. 重新執行 build.py 產出最新計畫書，連結即自動更新為最新雲端網址。
